# **App Name**: Radau Recreation

## Core Features:

- Design Replication: Mirror the design and layout of the Radau app website.
- Interactive Elements: Copy the interactive elements of the Radau website.
- Content Replication: Include the same blog posts and content from the original Radau website.

## Style Guidelines:

- Primary color: Deep violet (#483D8B), evoking creativity and innovation.
- Background color: Light gray (#EEEEEE), providing a clean and modern backdrop.
- Accent color: Soft lavender (#D8CEE6), complementing the primary color for a balanced look.
- Headline font: 'Poppins', a geometric sans-serif for a modern and clean appearance.
- Body font: 'Inter', a grotesque-style sans-serif ensuring readability and a neutral aesthetic.
- Use simple, outline-style icons for intuitive navigation.
- Employ a responsive, grid-based layout to ensure adaptability across devices.
- Incorporate subtle, modern animations such as fade-in effects during transitions.
