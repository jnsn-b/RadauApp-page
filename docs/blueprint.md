# **App Name**: RadauApp Website

## Core Features:

- App Overview: Display information about the RadauApp, including its purpose and key features.
- Benefits Section: Showcase the benefits of RadauApp, like saving money, reusing devices, and ensuring data privacy.
- FAQ Section: Present an FAQ section to answer common questions, such as how to lock the iPhone to a single app or how to manage playlists.
- Personalized Recommendations: Implement a tool that provides personalized content suggestions. This AI Tool recommends music, podcasts, or radio stations based on user age, preferences, and usage patterns.

## Style Guidelines:

- Primary color: Use a calming blue (#3498db) to convey trust and reliability.
- Secondary color: Implement a soft green (#2ecc71) to symbolize sustainability and eco-friendliness.
- Accent: Yellow (#f1c40f) for interactive elements and CTAs, conveying playfulness.
- Clear and readable fonts optimized for web viewing, such as Open Sans.
- Use simple, intuitive icons representing key features (music notes, playlists, settings).
- Clean, user-friendly layout with clear sections and minimal distractions.
- Subtle animations for transitions and interactive elements to engage users.
